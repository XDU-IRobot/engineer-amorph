# ⽐赛模式下的组合逻辑规则

⽐赛模式下,⾸先⽤⼏条规则保证所有设备都按预期运⾏,程序掌握的信息和机器⼈的物理情况完全 ⼀致。

- 1. 若同时丢失VT03图传和SBUS遥控器的连接,整⻋强制进⼊急停状态。
- 2. 若任一子系统对应的拨杆拨到下（急停），退出比赛模式，并使所有子系统急停。
- 2. 任⼀注册过的设备离线,整⻋急停。
- 3. 进⼊⽐赛模式⾸先对所有需要校准的机构进⾏校准。若某项校准失败,则整⻋急停。
- 4. 当检测到左臂夹⽖、右臂夹⽖、图传杆任⼀机构未校准时,整⻋急停。
- 5. 急停导致系统退出⽐赛模式,此时需操作遥控器使所有⼦系统⽆⼒,再重新进⼊⽐赛模式。

在满⾜上述保证的情况下,可以避免由于设备异常导致程序内信息和物理世界不⼀致,从⽽使⾃动序 列误操作,再从⽽导致的机构损坏。之后可以容许⼀些⾃动流程接管控制逻辑。

⽐赛模式下,整⻋有:"正常"、"收纳"、"⾃旋"三种构型。特别注意!机械臂处于Retract状态 下时处在收纳位置,此时若移动关节会导致机构损坏。以下规则保证,当机械臂只有在"预备过洞" 构型下会处于这种位置,且在这种位置时不会执⾏任何命令,直到退出"预备过洞构型",执 ⾏"Reset"序列回到正常构型位置之后。

"正常"构型:机械臂位于收纳位置之外,图传杆升起,云台Yaw轴不⾃稳(锁定在编码器零位),底 盘移动速度命令的参考前⽅为底盘的前⽅

"收纳"构型:机械臂位于收纳位置,图传杆降下,云台Yaw轴不⾃稳(锁定在编码器零位),底盘移 动速度命令的参考前⽅为底盘的前⽅

"⾃旋"构型:机械臂位于"Reset"位置,图传杆位于"Mid"位置,云台Yaw轴⾃稳,底盘根据输⼊量 旋转,底盘移动速度命令的参考前⽅为图传相机的朝向(通过云台Yaw轴编码器计算)

- 1. "正常"构型下,按xbox⼿柄上的左摇杆/右摇杆(LS/RS)使对应的机械臂执⾏"Reset"序列。
- 2. "正常"构型下,按xbox⼿柄上的X键进⼊"收纳"构型,两条机械臂执⾏"Retract"序列,移动 到底盘⾥的收纳位置,然后图传杆降下到"Down"位置。
- 3. "收纳"构型下,再按⼀次"X"键,图传杆继续降下到"ForceDown"位置。
- 4. 处于"收纳"构型下时,按xbox⼿柄上的Y键退出"收纳"构型。先使图传杆升起,然后机械臂执 ⾏"Reset"序列回到初始⼯作位置。
- 5. 只有当整⻋处于"正常"构型时,按xbox⼿柄上的LT/RT扳机可命令整⻋进⼊"⾃旋"构型。机械 臂执⾏"Reset"序列回到初始⼯作位置,避免和图传杆⼲涉,然后,图传杆移动到"Mid"位置,底盘 进⼊"Spin"状态,⾃旋⻆速度w由扳机按下的深度决定,速度命令的参考前向为图传的朝向(通过 云台Yaw轴编码器计算)
- 6. "正常"构型下,⾃定义控制器使能后可以接管对应的机械臂。当任意⼀个⾃定义控制器使能时, 底盘进⼊⻳速模式,且IMU头追重置参考欧拉⻆、底盘速度命令输⼊⽣效。
